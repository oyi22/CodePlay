## JUDUL PROJEK : CODEPLAY
## Deskripsi Umum
CodePlay merupakan applikasi pemainan (mobike game) bertemakan pemrograman yang dikembangkan menggunakan flamework flutter. Game ini dirancang untuk melatih ketelitian dan pemahaman logika dasar pemrograman bagi junior developer melalui dua mode permainan utama yaitu SyntaxLab dan Syntax Showdown<br>
Berbeda dengan applikasi pembelajaran interaktif, CodePlay  berfokus pada aspek hiburan dan tantangan berfikir logis, bukan pada proses belajar formal. Pemain dihadapkan pada puzzle dan kuis berbasis sintax dari berbagai bahasa pemrograman seperti C++, Python, JavaScript, dan java<br>

## Teknologi yang digunakan
Pengembangan CodePlay menggunakan teknologi dan alat sebagai berikut: 
1. framework       : flutter<br>
2. language        : Dart<br>
3. IDE             : Visual Studio Code<br>
4. Target platform : Bisa beradaptasi dengan sistem operasi apapun<br>
5. Fokus proyek    : Perancangan UI/UX<br>
Pada tahap ini, implementasi masih di sisi UI/UX tanpa integrasi logika database.

## Tujuan Proyek : 
Tujuan utama proyek ini adalah : 
1. Memenuhi syarat UTS pada Matkul Pemrograman Bergerak<br>
2. Merancang tampilan dan alur interaksi user untuk sebuah game bertema pemrograman <br>
3. Menyediakan konsep permainan yang mengasah kemampuan berfikir logis dan pemahaman sintaks melaluui element puzzle dan kuis<br>
1. Membangun fondasi awal untuk pengembangan game yang dapat dikembangkan lebih lanjut dengan sistem dinamis dan basisdata<br>

## Fitur yang dirancang 
### Syntax_Lab (mode puzzle syntax)
1. Komponen utama = Area susun puzzle, kumpulan potongan kode, dan area output<br>
2. Tujuan Permainan = Menghasilkan output yang benar sesuai urutan sintax dan sesuai dengan output tantangan, dan hint jawaban<br>
3. Fokus Perancangan = Interaksi drag-and-drop dan validasi posisi balok<br>

### Syntax_Showdown (mode quiz syntax)
1. Komponen utama = Tampilan soal, pilihan jawaban dan indikator hasil<br>
2. Tujuan Permainan = memilih pilihan ganda yang sesuai dengan output, jika benar maka point di tambah 5, dan jika salah maka juga akan di kurangi 5. dan akan muncul popup<br>
3. Fokus Perancangan = Interaksi quiz dan juga popup yang muncul<br>

## Rancang UI/UX
Desain antarmuka dibuat dengan pendekatan minimalis dan fokus pada keterbacaan elemen sintaks, warna, ukuran tombol dan struktur halaman dirancang agar menyerupai suasana bermain sekaligus meberikan kesan professional bagi pengguna dengan latar belakang pemrograman, rancangan dibuat menggunakan component dasar flutter 

## Kesimpulan
Proyek CodePlay merupakan rancangan awal dari game bertema pemrograman yang ditujukan bagi junior developer,
Fokus pengembangan saat ini adalah pada perancangan tampilan dan navigasi aplikasi menggunakan Flutter, tanpa integrasi sistem backend atau logika permainan. Aplikasi ini diharapkan dapat menjadi dasar pengembangan game logika berbasis sintaks pemrograman yang interaktif dan menantang pada tahap berikutnya
